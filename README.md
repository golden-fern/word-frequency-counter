Supported languages: English/en, Spanish/es

Instructions for use from release:
1. Double-click the .exe file to run it.
2. When prompted to enter a language, use the 2-letter language codes IN LOWERCASE. en for English, es for Spanish, etc. You can enter as many language codes as you would like.
3. When prompted to enter a filepath, enter the FULL LOCATION OF THE FILE ON YOUR PC. 
     a. I recommend making a folder somewhere on your PC to store your .txt files in. 
     b. The filepath should be something like "C:\textfiles\file.txt". 
     c. DO NOT INCLUDE THE QUOTATION MARKS IF YOU USE WINDOWS' BUILT IN "Copy As Path" FEATURE. THE PROGRAM WILL CRASH.
     d. Make sure the filepath is spelled correctly. If the program cannot find your file, it will crash.
4. The output will be saved as a .json file in the same location as your .txt file.
5. You can close the program by simply exiting out of the window.

How to run with run.bat(WINDOWS ONLY):
1. Download the source code as a .zip file.
2. Unzip to a folder.
3. Double click run.bat and click 'trust' on the prompt.

NOTE: a .bat file is a type of file on Windows that automatically executes code in the command prompt. They can be dangerous if you do not know the contents of the file. You can read all commands in a .bat file by right-clicking and opening it in notepad. This one is just an automated way to do the same thing as running via Terminal, so all it contains is the command "py main.py"

How to run with VSCode:
1. Download the source code as a .zip file.
2. Unzip to a folder. Make sure it is not in a folder synced with OneDrive.
3. Open the folder in VSCode and trust it so you can run the .py file.
4. Put your input .txt file in the same folder as main.py or copy your text into default_input.txt.
5. Run main.py and follow the prompts in the terminal.

How to run with command prompt:
1. Download the source code as a .zip file.
2. Unzip to a folder.
3. Open the folder.
4. Put your input .txt file in the same folder as main.py or copy your text into default_input.txt.
5. Right-click and press "Open in Terminal".
6. Enter the command "py main.py" into the terminal and follow the prompts.

The output file will be a .json file with the same name as the .txt file in the same folder as main.py. You can open it with a text editor like Notepad or Notepad++, or you can read it in VSCode if you are running through that.

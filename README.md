Only compatible with Windows currently. 
Supported languages: English, Spanish

How to run with VSCode:
1. Download the source code as a .zip file.
2. Unzip to a folder. Make sure it is not in a folder synced with OneDrive.
3. Open the folder in VSCode and trust it so you can run the .py file.
4. Put your input .txt file in the same folder as main.py or copy your text into default_input.txt.
5. Run main.py and follow the prompts in the terminal.

How to run with command prompt:
1. Download the source code as a .zip file.
2. Unzip to a folder.
3. Open the folder.
4. Put your input .txt file in the same folder as main.py or copy your text into default_input.txt.
5. Right-click and press "Open in Terminal".
6. Enter the command "py main.py" into the terminal and follow the prompts.

The output file will be a .json file with the same name as the .txt file in the same folder as main.py. You can open it with a text editor like Notepad or Notepad++, or you can read it in VSCode if you are running through that.
